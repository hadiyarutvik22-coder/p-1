Personal Data Collector

About the Project

This Python program collects basic details from the user and demonstrates Python data types, type casting, basic arithmetic operations, approximate birth-year calculation, and variable/type inspection.

How It Works

  1. Welcomes the user.
  2. Collects name, age, height, and favorite number.
  3. Uses type casting for numeric input.
  4. Calculates an approximate birth year.
  5. Displays a user summary.

Sample Input

  • Name: rutvik
  • Age: 18
  • Height: 6.07 meters
  • Favorite number: 7
